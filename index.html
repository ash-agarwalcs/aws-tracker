Your plan and progress live in a private GitHub repository. Connect this browser once, and every tick is saved there.

Connect

  1. Create a token on GitHub. The name, expiry and permission are filled in for you.
  2. Under Repository access choose Only select repositories and pick the repository named below.
  3. Check that Permissions shows Contents: Read and write, then press Generate token and copy it.
  4. Paste it here.

The token is kept in this browser and sent only to api.github.com. Sign out removes it. A token made this way can reach that one repository and nothing else.
